# Velto Brand Asset Manifest

Use only the official Velto assets supplied for this project.

## Required files

- `public/brand/velto-logo.png` — transparent production logo derived only by cropping transparent canvas from the supplied official PNG; artwork must remain unchanged.
- `docs/brand/source/velto-logo-original.png` — untouched supplied official PNG source.
- `docs/brand/velto-logo-reference.jpg` — untouched supplied white-background logo reference.
- `docs/brand/velto-company-profile.pdf` — supplied 16-page Velto company profile for visual-brand reference.

## Source rules

- Never redraw, trace, reconstruct, or substitute the logo.
- Do not use typed text as a replacement for the logo.
- The company profile is a visual-principles reference, not a website template.
- Preserve the approved Velto brand roles and design tokens in `docs/PROJECT-BUILD-SPEC.md`.
