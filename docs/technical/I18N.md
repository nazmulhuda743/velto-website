# Bangla / English (i18n)

Status: **PR 1 of the rollout (foundation + site chrome + homepage).** Bangla stays **off** in
production (`NEXT_PUBLIC_BANGLA_ENABLED` unset) until every public page is translated and the
owner has approved the copy in `docs/content/BANGLA-REVIEW.md`.

## Decisions (owner, 25 Sep 2026)

- Bangla has its own URLs: `/bn/...` (`/bn`, `/bn/pricing`, …). English keeps today's URLs.
- Scope: public site, forms (book / quote / track) and customer account pages. Admin stays English.
  Privacy / Terms / Cookies get Bangla only after a legal review.
- Bangla digits for prices, dates and sectors (৳৪৯৯, সেক্টর ১১). Phone and order numbers stay Western.
- Claude drafts standard Bangla (প্রমিত বাংলা); the owner reviews before it goes live.

## How it works

- **Routing.** Every public page lives in `src/app/[lang]/(site)/…` with `[lang]` = `en` | `bn`.
  `src/proxy.ts` rewrites unprefixed URLs to `/en/...` (English URLs never change), serves `/bn/...`
  as is, redirects `/en/...` to the plain URL (308), and while Bangla is off redirects `/bn/...` to
  English (307). `app/[lang]/layout.tsx` is the root layout (`<html lang>`); admin has its own root
  layout. Unknown public URLs reach `[lang]/(site)/[...missing]` and get the site 404 in their
  language; unknown `/admin/*` URLs get `admin/not-found.tsx`. (Unknown `/api`, `/go` and `/auth`
  URLs show Next's plain 404.)
- **Language in code.** Server Components: `getLocale()` (`src/lib/i18n/server.ts`, via
  `next/root-params`, falling back to the proxy's `x-velto-locale` header). Client Components:
  `useLocale()`. Text: `dictionary(locale)` from `src/content/i18n` (`en.ts` is the source; `bn.ts`
  must have the same keys, enforced by TypeScript). `fill()` inserts values and switches digits.
- **Links.** Public components import `Link` from `@/components/i18n/Link`, which adds `/bn` on
  Bangla pages. Plain `<a href="/…">` must use `localizeHref()`. Redirects use `localHref()` /
  `loginRedirectPath()`.
- **Switcher.** `LanguageSwitcher` (header, mobile menu, footer) links to the same page in the other
  language and remembers the choice in `velto_lang`; the proxy then opens that language for
  unprefixed URLs.
- **SEO.** `pageMetadata()` / `alternatesFor()` give each language its own canonical URL and, while
  Bangla is on, `hreflang` en / bn / x-default. The sitemap lists both languages.
- **Privacy.** `/bn/account*`, `/bn/login` etc. are private paths exactly like the English ones (no
  GTM, no first-party analytics, order numbers redacted).
- **Ops data stays English.** Booking values sent to Ops (area labels, service slugs, item lines) do
  not change with the page language.
- **Typography.** Noto Sans Bengali supplies Bangla glyphs (only downloaded for Bangla text).
  `globals.css` resets letter-spacing and loosens heading line-height on `html[lang="bn"]`.
