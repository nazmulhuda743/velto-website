# Velto Brand Source Assets

This directory documents the official Velto brand references required by the build.

## Required production assets

Place the supplied source files at:

- `public/brand/velto-logo.png`
- `docs/brand/velto-company-profile.pdf`

If an official white/reversed logo variant is supplied, place it beside the main logo with an explicit filename such as:

- `public/brand/velto-logo-white.png`

## Rules

The website is a refinement and digital evolution of the existing Velto identity, not a rebrand.

The build agent must use the actual supplied logo artwork and must not recreate, trace, redraw, or substitute it.

The company profile is a visual-principles reference, not a website template.

Preserve its useful brand DNA:

- deep navy identity
- Velto blue and brighter cyan accents
- limited purple accent inherited from the logo
- white space
- thin structural rules
- disciplined grids
- strong typography
- restrained editorial composition
- process/accountability expressed visually

Adapt the identity for a consumer website with more real photography, service discovery, price clarity, booking emphasis, trust proof, household context, and mobile usability.

## Working colour roles

The current working production tokens are defined in `docs/PROJECT-BUILD-SPEC.md`.

If future official vector artwork or a formal brand manual provides slightly different colour values, the official source values override the sampled hex values without changing the token roles.
